
# Proyecto Pokedex

Este proyecto es una aplicación web desarrollada en PHP que muestra una lista de Pokémon. Utiliza HTML, CSS, y PHP para mostrar los datos de una manera interactiva.

## Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener los siguientes elementos instalados:

- **Servidor web local con soporte PHP**: Puedes usar [XAMPP](https://www.apachefriends.org/es/index.html) o [WAMP](http://www.wampserver.com/).
- **Navegador web**: Cualquier navegador actualizado (Google Chrome, Firefox, Edge, etc.).

## Instrucciones para ejecutar el proyecto

### Paso 1: Clonar o descargar el proyecto

1. Si tienes Git instalado, clona este repositorio usando el siguiente comando:

   ```bash
   git clone https://github.com/MadelaineDiLauro22/pokedex.git
   ```

   Si no tienes Git, descarga el proyecto en formato `.zip` desde el botón **Download ZIP** en GitHub y descomprímelo en tu computadora.

### Paso 2: Configurar el servidor local

1. Si estás utilizando **XAMPP** o **WAMP**, asegúrate de que Apache esté ejecutándose.
2. Coloca la carpeta del proyecto en el directorio donde se alojan los archivos para el servidor local:

   - En **XAMPP**, coloca la carpeta dentro de `C:/xampp/htdocs/`.
   - En **WAMP**, colócala dentro de `C:/wamp64/www/`.

### Paso 3: Acceder al proyecto

1. Abre tu navegador web.
2. En la barra de direcciones, escribe la siguiente URL para acceder al proyecto:

   ```
   http://localhost/pokedex/
   ```

3. Deberías ver la aplicación Pokedex cargando en tu navegador.

## Estructura del Proyecto

- `index.php`: Archivo principal que muestra la lista de Pokémon.
- `styles.css`: Archivo que contiene los estilos CSS.
- `pokedex.php`: Archivo que contiene la lógica PHP para cargar la información de los Pokémon.
- `images/`: Carpeta que contiene las imágenes de los Pokémon.

## Modificar el Código

Si deseas realizar modificaciones:

1. Abre los archivos del proyecto en cualquier editor de código, como Visual Studio Code.
2. Modifica el código PHP, HTML o CSS según lo que quieras cambiar.
3. Guarda los cambios y actualiza la página en el navegador para ver los resultados.
